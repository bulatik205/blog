# fmt - формат

- fmt (format) — стандартный пакет для форматированного ввода/вывода

## Вывод

```go
fmt.Print("Hello", "World")      // HelloWorld (без пробелов)
fmt.Println("Hello", "World")    // Hello World\n (с пробелами и переводом строки)
fmt.Printf("Hello %s!\n", "World") // форматированный вывод
```

## Спецификаторы

| Спецификатор | Назначение | Пример |
|---|---|---|
| `%v` | Значение по умолчанию (универсальный) | `fmt.Printf("%v", 42)` → `42` |
| `%+v` | С именами полей структур | `{Name:Bob Age:30}` |
| `%T` | Тип значения | `int`, `string` |
| `%d` | Целое число | `42` |
| `%s` | Строка | `hello` |
| `%q` | Строка в кавычках (с экранированием) | `"hello"` |
| `%f` | Float | `3.140000` |
| `%t` | Bool | `true` |
| `%p` | Указатель | `0xc0000140a0` |
| `%x` | Hex | `ff` |

- Универсал - `%v`

## Ввод

```go
var name string
var age int

fmt.Scan(&name, &age)         // читает через пробелы
fmt.Scanln(&name, &age)       // читает строку до \n
fmt.Scanf("%s %d", &name, &age) // по формату
```
